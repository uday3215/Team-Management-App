# Team Management App

## Project Description

A full stack web application to manage team members using React, Node.js, Express, and MongoDB.

## Features

* Add team members
* Upload profile images
* View all members
* View individual member details

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB

## How to Run

### Backend

```bash
cd backend
node server.js
```

### Frontend

```bash
cd frontend
npm start
```

## API Endpoints

### Get All Members

GET /members

### Get Single Member

GET /members/:id

### Add Member

POST /members
